# Roadmap

## v0.1 foundation
- shared protocol
- shared memory storage and Agent CLI migration path
- low-footprint `kittd`
- OpenAI-compatible/Ollama model adapter
- ephemeral text/image HUD
- startup templates

## Deferred until a real use case requires it
- global hotkey daemon integration
- wake-word/STT/TTS/vision workers
- advanced Dreaming extraction from Agent CLI
- privileged tool execution/sandbox
- remote IPC
- installer/updater

Deferred items are intentional YAGNI decisions, not missing acceptance criteria for v0.1.
